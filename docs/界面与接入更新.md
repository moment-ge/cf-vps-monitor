# 界面与接入更新

## 仪表盘改版

概览页重排为运维仪表盘。原先桌面端会同时出现 68px 的品牌栏和 43px 的面包屑栏，两条导航壳合并成一条 60px 顶栏，侧边导航改为汉堡按钮唤出的抽屉。原来的球体主视觉占 440px 且左侧节点清单与下方列表重复，现在压缩成 296px 的顶部条：左半是六格汇总，右半是球体加图例。状态胶囊和搜索筛选两条带合并成一行，并拆成状态与地区两组 chip。

节点卡片按参考主题 `upstream/glassmorphism`（MIT）的 NodeCard 结构重排：状态圆点、名称、状态徽标、收藏与更多按钮一行；地区行；CPU / 内存 / 硬盘 / 流量四格指标，每格是彩色图标、等宽数值、4px 进度条和绝对值；下面三个内嵌块给实时上下行、累计流量和到期剩余；最后是延迟与丢包的色条，取自该节点最近 16 次历史采样。进度条按占用上色：低于 60 为绿，60 到 90 为琥珀，90 以上为红。

配色取自同一主题的 oklch token 换算值。深色 `#0d1117` 底、`#161b22` 卡面；浅色 `#eef2f6` 底、白色卡面。背景使用低对比度的纯 CSS 网格，不使用图片、照片或壁纸。语义色 success `#22c55e`、warning `#eab308`、destructive `#ef4444`。指标图标沿用该主题的分色：CPU 天蓝、内存 翠绿、硬盘 橙、流量 紫。

球体不再使用绘制的陆块贴图，改为 260 个斐波那契球面顶点、按距离连出的网格线，以及两条带移动光点的倾斜虚线轨道环。它支持自动旋转、拖拽暂停、播放/暂停和复位；地区旗帜标记显示在线数，部分在线时显示在线数/总数。它仍然不表示真实地图或真实国界。

## 新增数据

- `nodes.traffic_limit`（迁移 `0004_traffic_quota.sql`，单位字节，0 表示不限）。后台节点表单以 GB 填写，卡片显示已用占比。
- 管理员接口 `GET /api/admin/overview` 附带 `recent`：每个节点最近 16 条历史采样的时间、延迟、丢包和上下行速率，供卡片的色条和汇总趋势线使用。一次窗口函数查询取回，不按节点逐个请求。
- `GET /api/visitor`：回显 `CF-Connecting-IP` 与 Cloudflare `request.cf` 中的国家、城市、运营商和 ASN。响应带 `Cache-Control: no-store`，不写日志也不入库。本地 `wrangler dev` 会返回 mock 值。

延迟和丢包本来就由探针采集并入库（`agent/main.go` 每轮做三次 TCP 探测），此前只在节点详情弹窗里显示，这次接到了卡片上。

## 视觉

布局参考：https://vps.bayunbai.com/ 。采用顶部导航、分层监控台卡面、双列指标、浅色与深色表面。整张卡片可点击打开详情，保留列表视图和每页 20 台节点。公开首页默认选中在线筛选并显示“在线节点”，增加抽象节点球体主视觉、旗帜标记和状态浮层；它不表示真实地图或真实国界，节点详情和后台仍展示定位数据。

桌面卡片使用细边框和有限的表面层次；手机端提高卡面不透明度，避免小屏内容与背景混杂。页面不加载背景图片，纯 CSS 网格背景不会增加被监控 VPS 的探针 CPU 或内存负载。`api-image` 生成的设计稿保留在 `design-drafts/api-images/`，仅用于构图和视觉语言参考，不作为生产背景资源。

### 全球定位

后台新增节点或编辑节点时可以填写地区、纬度和经度。地区用于提供可用的默认参考点；纬度和经度必须成对填写并通过范围校验（纬度 -90 至 90，经度 -180 至 180）。填写坐标后详情显示“管理员指定坐标”，否则显示“地区级近似位置”，避免把近似位置误认为 VPS 的精确地址。球体和平铺地图仅在管理员视图展示，包含活动节点的状态和位置。游客使用匿名状态列表，公开接口不提供坐标或原始节点 ID。

## 准确性

创建节点仅建立记录，系统和硬件指标由对应节点密钥的真实探针提供。节点名称即使写成“512 MB”，探针上报 36 GB 后也显示 36 GB，不根据名称猜测数据。

首报弹窗检测有效上报并确认接入。概览隐藏过期动态指标，保留最后上报时间；详情明确标记样本时间。管理页自动刷新，浏览器用服务器时间推算离线状态，刷新失败也会让旧样本过期。

本地演示配置无法接入生产站点，禁止直接下载用于远程 VPS。正式部署后，需要在正式站点创建节点并下载对应配置。

## 验证

20 项测试通过，类型检查和生产构建通过。浏览器验证待接入、真实 macOS 首报后确认、在线筛选、手机浅色与深色、历史详情、整卡点击，以及桌面四列卡片。390 px 手机端卡片和弹窗无横向溢出，图表实际宽度 303 px，1440 px 桌面四列卡片无内部溢出。

## 表单控件收口

后台和公开页的下拉框统一使用 Radix Select，支持键盘导航、焦点管理、选中指示和弹层定位；复选框使用 Radix Checkbox，备注字段使用统一 Textarea。业务表单不再直接渲染原生 `select`、`textarea` 或 checkbox，输入尺寸、边框、焦点环和暗色主题由统一 UI 原语控制。页面主体与球体容器关闭背景图片和装饰网格，保持纯色运维界面；球体本身仍是抽象点阵网络，不代表真实地图。

本轮 `npm run check`、`npm run build`、定位/节点状态测试和发布包校验均通过。完整 API 测试在受限沙箱中因 Miniflare 无法监听 `127.0.0.1` 端口而超时取消，未出现业务断言失败；部署前请在可监听本地端口的环境重新执行 `npm test`。

本轮临时私有验收节点已归档。Cloudflare 登录与真实低配 VPS 长期测试仍是外部待办。
